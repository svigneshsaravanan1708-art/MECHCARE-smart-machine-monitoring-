# MechCare – Smart Industrial Machine Health Monitoring System

## About
MechCare is a Python-based desktop application designed to monitor industrial machine conditions and support predictive maintenance.

## Features
- Machine Registration
- Machine Health Analysis
- Temperature Monitoring
- Vibration Monitoring
- Critical Alerts
- Inspection History
- Machine Comparison
- Role-Based Login
- Dashboard Analytics

## Technologies Used
- Python
- Tkinter
- CSV
- SQLite (where implemented)

## Purpose
To combine Mechanical Engineering knowledge with Python programming and develop a smart industrial maintenance solution.

## Developer
Developed as a Mechanical Engineering student project.
